Implementasi teknik image enhancement untuk berbagai kondisi citra menggunakan Python dan OpenCV.
## Metode yang Diimplementasikan
1. Gamma Correction – Citra Overexposed
2. Gamma Correction – Citra Underexposed
3. Laplacian Sharpening – Citra Blur
4. CLAHE – Citra Low Contrast
5. Median Filter – Salt-and-Pepper Noise
6. Mean/Average Filter – General/Grain Noise
7. Histogram Equalization – Distribusi Intensitas Tidak Merata
8. High-Pass Filter (Frequency Domain) – Penonjolan Detail dan Tepi
